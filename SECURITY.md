
# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of SeaPorts.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability related to SeaPorts, please do not report it through a public GitHub issue.

Instead, use GitHub's private vulnerability reporting feature.

To report a vulnerability:

1. Open the repository's Security tab.
2. Select "Report a vulnerability".
3. Provide a detailed description of the issue.
4. Include steps to reproduce the vulnerability, if possible.

Please avoid publicly disclosing vulnerabilities before they have been reviewed.

## Scope

This policy covers security issues related to:

- Repository infrastructure and configuration.
- GitHub Actions workflows.
- Scripts and tools maintained by SeaPorts.
- Other software components maintained within this repository.

Incorrect geographic data, missing ports, and inaccurate polygons are not security vulnerabilities. Please report those through GitHub Issues instead.

## Response

Reports will be reviewed as soon as possible.

Please provide enough information to reproduce and understand the reported issue.
