# SEAPORTS of the World
This repository contains a comprehensive dataset of seaports around the world, including their locations, codes and a geographical boundary for each port. The dataset is designed to be used for various applications, including logistics, shipping, and maritime research.

## Dataset Overview
The dataset includes the following information for each seaport:
- Port Name
- UN/LOCODE (United Nations Code for Trade and Transport Locations)
- Country
- Latitude and Longitude coordinates
- Geographical boundary (polygon coordinates)

## Current Status
Currently only ports in Nothern Germany have a geographical boundary defined. The dataset is a work in progress, and we plan to expand it to include ports from other regions in the future. Other data is available for all ports, including their names, codes, and locations.
